Verify with the code

POST /auth/email/verify with email + code — verifies and signs you in. The emailed link is the same credential, so using either one kills the other.

Didn't get it?

POST /auth/email/resend-verification answers the same for every address, so it reveals nothing. Read the new code from the inbox.

Or the link

POST /auth/email/verify with token — verifies the address but does not sign you in: it may have been opened on another device than the one waiting.
