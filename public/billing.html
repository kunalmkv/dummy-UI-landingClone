Billing belongs to the organization; any of its workspaces is the door. Reading it needs workspace ADMIN or OWNER (EDITOR and VIEWER get FORBIDDEN). Changing the plan or the extra seats needs the organization's OWNER — an org ADMIN is refused, and so is a workspace owner who does not own the organization. No payment is taken: plans are switches until payments exist.

Change plan — POST /workspaces/:id/billing/plan

The same key with the same planId replays the first answer and runs nothing again; the same key with a different planId is refused. A blank key sends no header. A downgrade below what is in use is refused with DOWNGRADE_BLOCKED.

Extra seats — POST /workspaces/:id/billing/seats

An absolute number, not an increment. It must be a JSON number: tick the box to send it as a string and see the refusal. A limit below the seats in use is refused with SEATS_BELOW_USAGE.
